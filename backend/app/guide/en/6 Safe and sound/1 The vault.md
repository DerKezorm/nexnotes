# The vault

For secrets there is the vault. A locked note is encrypted **on your device** before it goes to the server. The server and the operator see only encrypted data.

![The dialog "Set up the vault"](shots/vault.webp)

## Locking a note

1. Choose **"Lock"** in the note's menu.
2. The first time, set up the vault: a password only you know.
3. To read the note, type the password. After five minutes without use, or when you close the tab, the note is locked again.

## Important

- **A forgotten password means the content is gone.** Nobody can restore it, not even the operator.
- The title stays readable so that you find the note. Write nothing secret in the title.
- Locked notes are neither searched nor read by text recognition.
