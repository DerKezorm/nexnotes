# Read links

To show a note to someone without an account, tick **"Link to read"** in the dialog "Share". Whoever has the link can read the note, but not change it.

![A read link with its last day](shots/share-link.webp)

## What to know

- A link always runs out. You choose its last day.
- nexnotes shows the address only once, right after making it. Copy it at once.
- **"Revoke link"** ends it immediately. A new link replaces the old one.
- Settings › Security lists all your read links at a glance.

The operator can turn read links off for the whole server.
