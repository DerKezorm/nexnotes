# Welcome to nexnotes

Good to have you here! nexnotes is for quick notes: write it down, find it again, done. This guide is itself a folder of ordinary notes. Read it, try things out in it, change it or delete it once you no longer need it.

![nexnotes with the sidebar, the list of notes and an open note](shots/overview.webp)

## How nexnotes is laid out

- **The sidebar on the left:** at the top the tiles "Inbox", "All notes" and "Shared with me", below them your folders, the smart folders and your tags.
- **The list in the middle:** the notes of the folder you chose.
- **The note on the right:** this is where you write. Several notes sit side by side as tabs.

nexnotes saves what you write right away. There is no save button.

## Try it now

This checklist is real. Tick off what you know already:

- [ ] Make a new note
- [ ] Make a folder with a symbol
- [ ] Search for something with Ctrl+K
- [ ] Pin a note
- [ ] Open a second note beside the first

Need the guide fresh again later? Under **Settings › Appearance**, "Make the guide again" adds it once more. Your own changes stay untouched.
