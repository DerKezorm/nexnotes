# nexdeck-Karte

Auf deinem **nexdeck**-Dashboard kann eine Karte deine angehefteten Notizen oder eine Checkliste zeigen. Auf der Karte hakst du Punkte direkt ab.

## So verbindest du nexdeck

1. In nexnotes unter **Einstellungen › Verbindungen** einen API-Token anlegen. Zum Abhaken braucht er „lesen und schreiben“.
2. In nexdeck eine Karte „nexnotes“ hinzufügen, die Adresse von nexnotes und den Token eintragen.
3. Wählen, was die Karte zeigt: die angehefteten Notizen oder eine bestimmte Checkliste.

![Ein Token für die nexdeck-Karte](shots/token-dialog.webp)

Was auf der Karte abgehakt wird, steht im Verlauf der Notiz als „nexdeck“ mit dem Namen des Tokens.

Gut zu wissen: nexnotes bietet die Schnittstelle für die Karte schon an. Die Karte selbst kommt mit einer der nächsten Versionen von nexdeck.
