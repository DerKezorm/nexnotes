# Checklisten

Eine Checkliste legst du über das Häkchen-Symbol in der Werkzeugleiste an. Jede Zeile wird ein Punkt zum Abhaken. Mit Einrücken entstehen Unterpunkte.

![Eine Einkaufsliste mit erledigten Punkten](shots/checklist.webp)

## Erledigtes nach unten

Unter der Checkliste schaltest du **„Erledigtes nach unten“** ein. Abgehakte Punkte rutschen dann ans Ende, das Offene bleibt oben. In der Notizliste zeigt nexnotes, wie viele Punkte schon erledigt sind, etwa „2 von 5“.

## Zum Ausprobieren

- [x] Milch
- [x] Brot
- [ ] Äpfel
- [ ] Kaffee
- [ ] Blumen für Oma

Notizen mit offenen Punkten findest du jederzeit im intelligenten Ordner **„Offene Checklisten“** in der Seitenleiste.
