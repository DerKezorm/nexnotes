# Formatieren

Über der Notiz steht die Werkzeugleiste: Textstil (Überschrift, Zwischenüberschrift, Fließtext), fett, kursiv, Textmarker, Listen, Checkliste, Tabelle, Link und mehr. Sie bleibt beim Scrollen oben stehen.

![Die Werkzeugleiste über einer Notiz](shots/toolbar.webp)

## Die Formatleiste an der Markierung

Markierst du Text, erscheint direkt daneben eine kleine Leiste mit dem Wichtigsten: **fett**, *kursiv*, unterstrichen, ~~durchgestrichen~~, ==Textmarker==, Link und „Formatierung entfernen“.

![Die Formatleiste über markiertem Text](shots/selection-bar.webp)

## Ein paar Abkürzungen

| Tasten | Wirkung |
|---|---|
| Strg+B | fett |
| Strg+I | kursiv |
| Strg+U | unterstrichen |
| Strg+Alt+K | Link |
| Strg+Z | rückgängig |

Auf dem Mac nimmst du ⌘ statt Strg. Den Textmarker gibt es in fünf Farben: Honig, Grün, Blau, Rosa und Violett.
