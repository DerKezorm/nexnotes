# Links zum Lesen

Willst du eine Notiz jemandem zeigen, der kein Konto hat, setz im Dialog „Teilen“ den Haken bei **Link zum Lesen**. Wer den Link kennt, kann die Notiz lesen, aber nicht ändern.

![Ein Link zum Lesen mit Ablaufdatum](shots/share-link.webp)

## Was du wissen solltest

- Ein Link läuft immer ab. Den letzten Tag wählst du selbst.
- Die Adresse zeigt nexnotes nur einmal, direkt nach dem Anlegen. Kopier sie gleich.
- **„Link widerrufen“** macht ihn sofort ungültig. Ein neuer Link ersetzt den alten.
- Unter Einstellungen › Sicherheit siehst du alle deine Links zum Lesen auf einen Blick.

Der Betreiber kann Links zum Lesen für den ganzen Server abschalten.
